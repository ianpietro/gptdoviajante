# VEROA — Direção Visual e UI Foundation (Ocean & Mineral Palette)

## 1. Território Visual: Editorial Intelligence (Ocean, Water, Mist & Minerals)

A interface de VEROA transmite **sofisticação, calma, inteligência, orientação e precisão em tempo real**. O visual é leve, tátil e predominantemente claro (70% base branca/névoa).

---

## 2. Paleta Oficial de Cores (Design Tokens)

| Token CSS | Cor HEX | Função & Diretriz de Aplicação |
| :--- | :--- | :--- |
| `--veroa-white` | `#F8FAF9` | **70% Base Principal:** Backgrounds limpos, cards primários, ambiente dominante. |
| `--veroa-background` | `#EEF2F1` | **Fundo Secundário:** Substitui áreas cinza genéricas, seções secundárias e respiros. |
| `--veroa-blue` | `#536A79` | **Cor Institucional Principal:** Botões primários, elementos selecionados, navegação ativa, ícones chave, links de alta hierarquia. |
| `--veroa-blue-dark` | `#344A59` | **Forte Hierarquia:** Títulos de destaque, estados de hover primários, cabeçalhos de alto contraste. |
| `--veroa-seafoam` | `#A9CBC8` | **Inteligência Contextual & Highlight:** Veroa Now, viagem em andamento, badges de recomendação inteligente, indicadores positivos. |
| `--veroa-seafoam-light` | `#D4E5E1` | **Fundos Suaves & Badges:** Cards destacados, áreas secundárias verde-água, chips ativos. |
| `--veroa-text` | `#26343B` | **Texto Base Legível:** Substitui o preto puro em favor de um mineral grafite escuro e calmo. |
| `--veroa-sand` | `#D9CEBC` | **Neutro Quente Complementar:** Uso estritamente moderado quando necessário contraste tátil mais quente. |

---

## 3. Hierarquia Cromática

```
[#F8FAF9] Branco Névoa (70%)
   └── [#536A79 / #344A59] Azul Oceano / Mineral (20% Institucional & Estrutura)
         └── [#A9CBC8 / #D4E5E1] Seafoam Verde-Água (10% Inteligência Contextual & Veroa Now)
               └── Cores Funcionais Harmonizadas (Status, Alertas & Perigo)
```

---

## 4. Tipografia

- **Sora (Google Fonts):** Headings, Números em Destaque, Wordmark VEROA.
- **Inter / Plus Jakarta Sans (Google Fonts):** Corpo de texto, formulários, tabelas e dados operacionais.
